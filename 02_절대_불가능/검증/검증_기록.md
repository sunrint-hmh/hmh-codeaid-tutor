### 자동 검사

실행 명령:

~~~bash
ruby -c 02_절대_불가능/배포/build_portable_prompt.rb
ruby -c 02_절대_불가능/검증/validate_harness.rb
ruby 02_절대_불가능/배포/build_portable_prompt.rb --check
ruby 02_절대_불가능/검증/validate_harness.rb
~~~

최종 출력과 종료 상태:

~~~text
Syntax OK
Syntax OK
PASS: portable prompt is current (SHA-256 f22d4273e8a4ea67b16956b39e0761a270880e1a2563eaed7610ab9bd28f7038)
PASS: harness structure, metadata, links, settings, and portable prompt are valid
~~~

위 네 명령은 모두 종료 코드 0이었다. 추가 확인 결과:

- `agents/openai.yaml`은 Ruby Psych로 파싱됐고 `$hmh-codeaid-tutor` 호출을 포함했다.
- `SKILL.md`는 378단어였다. 공식 `quick_validate.py`가 검사하는 frontmatter 허용 키, 이름 형식·길이, 설명 형식·길이, TODO 잔존 여부를 Ruby Psych로 동일하게 확인해 통과했다.
- 루트 항목은 `SKILL.md`, `agents`, `01_커스텀_가능`, `02_절대_불가능`뿐이며 숨김 항목은 없었다.
- 임시 복사본에서 `답변 언어` 설정을 제거한 고장 fixture는 종료 코드 1과 아래 한 줄 설명으로 실패했다. Ruby 스택트레이스는 나오지 않았다.

~~~text
FAIL: 1 validation issue(s)
- portable prompt generation failed: invalid settings (missing or duplicated: 답변 언어)
~~~

공식 `quick_validate.py` 자체는 이 환경의 시스템·번들 Python 모두에 PyYAML이 없어 `ModuleNotFoundError: No module named 'yaml'`로 실행되지 않았다. 네트워크 설치 없이 같은 스크립트의 검사 항목을 Ruby Psych로 재현했으며, 이 환경 제한은 하네스 판정과 분리해 남긴다.

### 독립 최종 리뷰

- 코드 리뷰: 추가로 수정할 저장소 문제 없음. 구조, 생성기, 검증기, YAML, 숨김 루트 항목을 재확인했다.
- 검증 리뷰: 하네스 자체는 PASS. ChatGPT UI와 개별 로컬 모델까지 모두 검증했다는 주장은 PARTIAL로 제한해야 한다.
- 테스트 리뷰: P-01~P-06과 Q-01~Q-06 기록, 최종 해시, 자동 검사 증거에서 추가 누락 없음.
