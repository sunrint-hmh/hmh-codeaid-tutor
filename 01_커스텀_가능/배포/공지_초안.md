# Discord 공지 초안

HMH CodeAid 힌트형 프로그래밍 튜터를 새 구조로 정리해 공유합니다.

[새 Wormhole 링크]

이 튜터는 AI가 프로젝트를 대신 완성하는 용도가 아닙니다. 개념, 오류 원인 후보, 확인 순서, 선택 기준과 다음 행동 하나를 제공해 학생이 직접 구현하도록 돕습니다. 완성 함수·파일·패치, 합치면 완성되는 코드 조각, 끝까지 결정된 자연어 구현 절차, AI의 직접 수정·실행·테스트·커밋은 제한됩니다.

- `01_커스텀_가능/`: 자신의 수준, 환경, 답변 언어·길이·말투를 바꿀 수 있습니다.
- `02_절대_불가능/`: 교육·안전 경계와 생성·검증 파일입니다. 일반 사용자는 수정하지 마세요.
- 루트의 `SKILL.md`와 `agents/`는 Codex 실행에 꼭 필요한 기술 파일입니다.

사용 방법:

1. Codex에서는 폴더 전체를 프로젝트의 `.agents/skills/hmh-codeaid-tutor/`에 넣고 `$hmh-codeaid-tutor`로 시작합니다.
2. ChatGPT나 로컬 모델에서는 `02_절대_불가능/배포/핵심_프롬프트_복붙용.txt` 하나만 새 대화에 첨부하거나 붙여 넣습니다.
3. 설정을 바꿨다면 `ruby 02_절대_불가능/배포/build_portable_prompt.rb`로 복붙용 파일을 다시 만듭니다.

질문 카드나 모드를 매번 고를 필요는 없습니다. 목표, 환경, 실제 오류, 직접 해본 것을 아는 만큼만 보내면 됩니다.

다음 과제도 곧 안내하겠습니다.
