# HMH CodeAid 튜터 시작하기

이 패키지는 AI가 평가 대상 프로젝트를 대신 완성하지 않고, 학생이 직접 이해·구현·실행·설명하도록 돕는 힌트형 프로그래밍 튜터다.

## 두 영역과 필수 루트 파일

- `01_커스텀_가능/`: 학생이나 게시자가 안전하게 바꿀 수 있는 설정, 사용 안내, 질문 예시, 공지 초안만 둔다.
- `02_절대_불가능/`: 교육·안전 경계, 생성 프롬프트, 생성기, 검증, 참고자료를 둔다. 일반 사용자는 수정하지 않는다.
- 루트에는 Codex가 스킬을 찾고 표시하는 데 꼭 필요한 `SKILL.md`와 `agents/`만 둔다.

튜터의 답변 방식을 개인화할 곳은 `01_커스텀_가능/내_설정.md` 하나다. 같은 폴더의 사용 안내, 질문 예시, 공지 초안은 문구를 고쳐도 보호 규칙을 바꾸지 않는다.

## 가장 먼저 할 일

1. `01_커스텀_가능/내_설정.md`에서 각 콜론 뒤 값만 자기 상황에 맞게 바꾼다.
2. `02_절대_불가능/` 아래는 그대로 둔다.
3. 복붙용 프롬프트를 쓸 경우 아래 명령으로 생성물을 갱신한다.

```bash
ruby 02_절대_불가능/배포/build_portable_prompt.rb
```

4. 아래에서 사용하는 AI에 맞는 방법을 고른다.

## Codex에서 사용

가장 안정적인 방법은 전체 폴더를 학생 프로젝트의 `.agents/skills/hmh-codeaid-tutor/`에 두고 새 작업에서 다음처럼 시작하는 것이다.

> `$hmh-codeaid-tutor`로 이 프로그래밍 질문을 힌트 중심으로 도와줘.

자동 발견을 사용할 수 없는 환경에서는 `hmh-codeaid-tutor/SKILL.md`를 먼저 읽고 적용하라고 명시한다. 첫 답변이 질문 카드를 요구하지 않고 튜터 준비 상태, 직접 할 일 하나, 확인 질문 하나를 보여 주는지 확인한다.

## ChatGPT 또는 다른 대화형 AI에서 사용

새 대화에 `02_절대_불가능/배포/핵심_프롬프트_복붙용.txt` 하나만 첨부하거나, 그 파일 전체를 첫 메시지에 붙여 넣는다. 다른 파일은 넣지 않아도 된다.

> 첨부한 HMH CodeAid 프롬프트를 이번 대화에 적용해 줘.

## 로컬 모델에서 사용

같은 복붙용 파일을 시스템 프롬프트나 첫 메시지에 넣는다. 모델별 규칙 준수 편차가 크므로 처음 배포할 때는 `02_절대_불가능/검증/검증_시나리오.md`를 실행한다.

## 질문하는 법

질문 카드나 모드 선택은 필수가 아니다. 그냥 질문해도 튜터가 모드와 힌트 단계를 고른다. 더 정확한 진단이 필요하면 다음 중 아는 것만 보낸다.

- 목표
- 언어·프레임워크·버전
- 기대한 결과와 실제 결과
- 오류 메시지 또는 관련 코드
- 직접 해본 것

짧은 예시는 `01_커스텀_가능/사용법/02_질문_예시.md`에 있다. API 키, 토큰, 비밀번호, 개인정보는 먼저 가린다.
